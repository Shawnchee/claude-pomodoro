# Claude Pomodoro

A small, cute, pixel-art pomodoro timer that lives in a floating always-on-top window. Cross-platform (macOS / Windows / Linux) via Electron.

## Run locally

```bash
npm install
npm start
```

## Assets

- `assets/work.gif` — plays while the timer is counting down (work phase)
- `assets/done.gif` — plays during break / idle

Swap the files in `assets/` to change the mascot animations.
